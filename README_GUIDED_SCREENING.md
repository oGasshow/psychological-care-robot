# 自然对话中的 PHQ-9 / GAD-7 辅助采集原型

本轮按用户新要求恢复两套量表相关的信息采集。网页不显示“准备好了”、题号、答题进度或逐题表单；首次说明用途并允许邀请后，通过自然话题过渡及口头同意进入采集。保留“停止相关信息整理”。不隐瞒心理信息整理用途，不宣称用户在不知情下完成了正式问卷。

## 实际链路

`用户最终转录 → 线索事件 → 陪伴/等待过渡 → 自然邀请 → 用户愿意继续 → 单话题澄清 → 频率复述与确认 → 后台辅助合计`

服务端通过当前云会话的 `session.update` 更新完整 instructions；接收 `session.updated` 后发出 `screening.policy_applied`。写入队列只返回 queued/applied=false，不能当成豆包已收到。更新在当前会话生效，不重启录音，也不伪造用户台词或把系统指令存成用户原话。

默认不启用辅助采集，需开始前勾选用途说明。每次只了解一个话题，不念量表名和题号；不要求用户表示“准备好了”。自然语言的“好/可以”等，仅在已记录到助手实际邀请后作为继续交流的确认。频率复述必须与待确认值一致；用户确认后才入计分条目。普通聊天、模糊回答、否认/转述/猜测不自动换算分数。当前是保守规则抽取，尚未接入任意自然语言的模型抽取器，较自由的表述可能需要进一步澄清。

两套均使用最近两周回顾窗，逐项 0—3，缺失保留 null；完整后才计算辅助总和。每个条目保留频率表达与确认对应的 external_message_id，可在原始记录中追溯。改写问法未验证等同标准施测，结果固定标记 `conversation_assisted`、`unverified`、`formal_assessment=false`；不输出临床分级、诊断或疗效。PHQ-9 自伤相关条目非零或出现明确危险表达时暂停继续采集，优先关怀与支持。

当前“允许过渡”只用探索性节奏规则：出现两次线索后等待，随后两个未匹配明显不适的不同用户回合才允许自然邀请；这不是情绪稳定检测器，更不是抑郁诊断。出现明显不适则暂停，拒绝后本次不再邀请。该规则仍需用户体验与专业评估，不据其声称已经判断情绪稳定。

## 检测器如何通知豆包

当前账号已有启用辅助采集的语音会话时，后端检测器调用：

```http
POST /api/robot-voice/screening-signal
Authorization: Bearer <记录所属用户的系统JWT>
Content-Type: application/json
```

```json
{
  "session_id": "voice_当前实际会话ID",
  "evidence_ids": ["user_当前会话内的实际最终转录ID"],
  "detector_version": "your-detector-version"
}
```

证据必须来自该账号当前会话中的最终用户转录；他人、过期会话、虚构证据、未启用采集均拒绝。模型地址、提示词、量表答案不能通过此接口直接注入。检测器结果仅表示“出现值得关注的线索”，先进入等待阶段，不直接下发连续问卷。

Windows 浏览器和 Pi 仍使用同一 WebSocket 协议，authenticate 可加 `guided_screening:true`。原 `screening.action` 的 ready/consent/pause/decline 控制兼容保留，但网页不展示 ready 或 consent 阶段按钮；主要交互使用口头邀请和答复。

## 持久化与报告

最终文字继续走既有 Outbox，after_close 上传。文字确认保存后，辅助结果写入增量表 `robot_voice_screening_results`。`GET /api/robot-voice/screening-results/{sid}` 只允许本人读取；删除原会话会同步删除辅助结果。结果保存失败会单独提示，不把已保存文字误报成保存失败。

报告 preview 附 `conversation_assessments`，页面独立显示“对话辅助采集 · 待核实”，缺项不出总分。这些分数不进入正式量表趋势或模型叙述事实包。更正原话后仍需重新核实，当前结果明确标记 `not_revalidated_after_edits`。当前不支持跨语音会话继续上次采集；网络或进程中断后，已确认原话可补传，但未保存的采集状态不能宣称恢复完成。

## 论文与适用边界

[Chen 等，NAACL 2024，SEGA](https://aclanthology.org/2024.naacl-long.452/) 对访谈问题、回答文字/音频/视频构建结构图，用 LLM 做原则引导的数据增强，在临床访谈数据上评估抑郁识别。它不是“无感量表生成”方案，也没有为本产品提供情绪稳定判定、PHQ-9/GAD-7 改写问法等效性或在线触发阈值。本轮未训练、复现或部署 SEGA；只预留它输出线索事件的接口，当前检测器是探索性规则。

量表口径参考 [NIH PHQ-9](https://www.nih.gov/node/19946)、[NIMH GAD-7 数据字典](https://nda.nih.gov/data-structure/cde_gad701)。正式使用前仍需核对选用中文版本、授权/适用人群并验证标准施测与对话采集的一致性、漏项、拒答、错误归因和真实体验。
